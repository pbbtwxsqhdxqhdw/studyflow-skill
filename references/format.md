# StudyFlow v1 格式

**英语按题型组织**

- 阅读理解每篇单独建一份材料，标题可用「阅读理解 A」「阅读理解 B」。同篇各题引用同一个材料 ID，题型标签写「阅读理解」。
- 七选五保留全文和编号空位。每空一题，每题使用相同的 A–G 选项，文字和顺序完全一致，题型标签写「七选五」。
- 完形填空保留全文和编号空位。每空一题，各题录入自己的选项，题型标签写「完形填空」。
- 语法填空保留全文、编号空位和括号提示词。每空一题，题型标签写「语法填空」。
- 完形、七选五、语法填空的材料标题写上对应的题型名。原文空位写作 `61 _____`，对应的小题写 `"blankNumbers":[61]`，并用 `materialId` 引用原文。各题型、各篇材料及各小题按原卷顺序连续排列。

**按 StudyFlow v1 打包**

- ZIP 根目录直接放 UTF-8 编码的 `manifest.json`，配图放在 `assets/`。纯文字题包也用 ZIP。清单顶层为 `{"version":1,"questions":[],"materials":[],"exams":[],"assets":[]}`。
- `questions` 每题写 `id`、`subject`、`type`、`stem`、`options`、`answer`。学科用语文、数学、英语、物理、化学、生物。题型用 `single`（单选）、`multiple`（多选）、`judge`（判断）、`blank`（填空）。解析写入 `analysis`，题型标签写入 `tags` 字符串数组。需显示原卷题号时，把「原卷第 16（1）题」这类标记单独写作题干首段。英语完形和七选五可用「41. 选择最恰当的一项」这类简短题干。
- 选项写成 `{"id":"A","content":"选项原文"}`，至少两个有效选项。答案数组存选项 ID，例如 `["B"]` 或 `["A","C"]`。判断题用 T、F 两个选项，答案只有一项。填空题的 `options` 为空数组，`answer` 按空格顺序填写字符串。可用 `accepted` 声明等价答案，每空一个数组并包含标准答案。草稿缺填空答案时，省略无法与答案对应的 `blankNumbers` 和 `accepted`。
- `materials` 每项写 `id`、`title`、`content`。题干、选项、解析和材料的纯文本可写字符串，分段可用内容块数组，段落块为 `{"type":"paragraph","text":"原文"}`。行内公式用 `$...$`，化学式可用 `\\ce{...}`，写入 JSON 时正确转义反斜杠。表格可用 `{"type":"table","headers":[...],"rows":[...]}`，或裁切为清晰原图。
- 配图用 `{"type":"image","assetId":"pack-fig-1","alt":"原题配图"}` 内容块引用，`assets` 中对应声明为 `{"id":"pack-fig-1","path":"assets/pack-fig-1.png","mime":"image/png"}`。支持 PNG、JPEG、WebP、GIF，图片文件名用英文字母、数字、点、短横线和下划线。保留图中坐标、标注和图例。题包最多 50 MB、10,000 题，单张图最多 15 MB。
- `exams` 每套写 `id`、`title`、`subject`、`questionIds`、`points`。题目 ID 按原卷顺序排列，分值逐题对应且为正数。原卷未标分时，默认每题 1 分并注明。每个题包使用专属 ID 前缀，题目、材料、练习和图片在各自数组内保持 ID 唯一。ID 以英文字母或数字开头，只用英文字母、数字、点、冒号、短横线和下划线，最长 128 字符。修订同一题包时沿用原题目、材料和练习 ID，替换图片内容时使用新图片 ID。

- 七选五和完形填空用 `single`，每个编号空位对应一道题。同一材料的题目连续排列，材料正文只录入一次。题型标签各写一个。
- 缺答案的草稿使用空答案数组。整个大题只有合计分值、缺少小问分值时可均分到可作答的全部小问（仅在全组均保留时），交付时注明。其他无法对应到单题的分值按未标分处理。
